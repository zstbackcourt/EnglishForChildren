# 微信小程序体验版 Implementation Plan

> For agentic workers: use superpowers:subagent-driven-development task-by-task with review.

**Goal:** 在 wechat 分支完成原生小程序迁移和本地测试，按用户最新授权先推送供云托管部署；真实发布条件满足后上传体验版。

**Architecture:** 原生小程序调用独立 Go 服务；按微信 openid 隔离家庭存档，复用 game handler。大图片与音频远程加载。

**Tech Stack:** Go 标准库、WXML、WXSS、CommonJS JavaScript、Node 内置测试。

**Spec:** docs/wechat-design.md
