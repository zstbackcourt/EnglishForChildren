# 新概念英语第一册冒险游戏方案

日期：2026-10-22。产品名：英语小小冒险家（Little English Adventure）。使用场景：家庭共用设备、多个儿童角色、本地 Go 服务器持久化存档。本文先于实现编写，后续取舍记录到 `docs/changes.md`。

## 目标与完成标准

把第一册学习变成可反复游玩的短单元：选择角色 → 地图选课 → 原声情景对话 → 互动挑战 → 获得奖杯 → 保存进度。每课一个独立单元，沿用教材 1–144 的编号，不能把两课合并后宣称覆盖全部课次。每次游玩建议 5–10 分钟，无生命扣除、付费、排行榜或连续登录惩罚。

完成标准：能创建与切换名字角色；刷新及重启后保留角色、逐课逐难度成绩、奖杯和对话位置；播放仓库 MP3 并按 LRC 逐句定位；三种难度有不同题型和奖励；重复通关不会重复领取奖励；电脑与手机可操作；有可运行测试、启动说明、素材映射、变更记录。

## 已核实的素材

- 仓库 `New-Concept-English` 保持原样，游戏代码放在工作区根目录，与素材仓库并列。
- 第一册 PDF 共 299 页，是无文本层的扫描件。PDF 第 5 页为 Lesson 1，第 7 页为 Lesson 2，第 13 页为 Lesson 5，不能依赖文件文本抽取。
- 第一册有 72 份美音 LRC，文件名如 `001&002－Excuse Me.lrc`；音频实际朗读奇数课，偶数课需使用对应奇数课音频复习，不冒充独立偶数课录音。
- 名为第一至四册英音的 ZIP 内只有一张 PNG，不包含英音音频。
- 内容导入需生成逐课 PDF 页码和音频配对表，音频正文要去掉 Lesson、标题和录音教学指令。缺失或无法可靠定位的内容必须在审计中报告。

## 方案比较与选择

| 方案 | 优点 | 成本与适用范围 |
| --- | --- | --- |
| 原生 JavaScript + Go，场景以 DOM/CSS 表现（选择） | 无前端构建依赖，文本与音频容易同步，手机适配和无障碍友好 | 适合地图、视觉小说式 RPG、答题；不做自由走动的动作游戏 |
| React + Phaser + Go | 适合大地图移动、复杂精灵动画 | 学习流程不需要物理引擎；增加资源加载和状态同步成本 |
| 纯静态网页 + 浏览器存储 | 原型最快 | 无法满足 Go 后端和服务器可靠存档要求 |

Go 使用标准库 HTTP 服务，前端使用 ES modules。家庭单实例使用带互斥锁、临时文件写入和原子替换的 JSON 存档；接口通过仓储层隔离，以后可替换 SQLite。默认监听 `127.0.0.1:8080`。不上传素材或角色数据到第三方托管服务。

## 游戏设计

### 角色与地图

首次输入 1–20 个字符的名字并选头像，服务器生成独立 ID。允许不同角色同名，切换时显示头像与创建信息，不把名字用作账号身份。地图分成 12 个章节，每章 12 课，展示完成度、当前课、三枚奖杯状态。允许自由选课，推荐继续未完成单元，避免家庭使用时被顺序锁定卡住。

### 对话与素材

奇数课为故事对话：原课插画场景、说话人标签（可靠角色标注优先，否则显示录音句子）、醒目的英文气泡、上一句/下一句/重播、播放速度、整段播放与时间轴。LRC 起点定位，下一句时间作为当前句终点；最后一句播放到音频结束。暂停和换课时停止旧录音。进入新课不自动播放声音。

偶数课为练习单元：展示本课标题与教材页，使用配对故事课的录音进行听辨、排序和拼写巩固；UI 明示录音来自配对课。首版统一练习引擎不等同于教材全部书面习题的数字化复刻，逐课题库质量在内容审计中单独记录。

### 三种难度

| 难度 | 辅助与题型 | 通过条件 | 首次奖励 |
| --- | --- | --- | --- |
| 萌芽 / 入门 | 句子可见，听音三选一，错后讲解 | 5 题至少答对 3 题 | 本课铜杯，10 星光 |
| 探险 / 进阶 | 听音补词，单词排序 | 5 题至少答对 4 题 | 本课银杯，20 星光 |
| 勇者 / 挑战 | 隐藏答案，听写关键单词 | 5 题全部正确 | 本课金杯，30 星光 |

题目由本课配置和原文派生，干扰项去重，接受大小写和句末标点差异，答案不由客户端自行决定。题目提交到 Go 后端判分；一次答题会话固定难度和题目，返回逐题反馈。每课每难度独立记最高分和尝试次数，奖励由服务器去重。答错不扣已获奖励，可重试。全部奖杯上限 432 枚；星光只统计首次通关获得的总和。

### 美术策略

奶油色纸张、森林绿、杏橙色、绘本式大卡片，界面中文引导、学习内容英文。教材场景是每课视觉来源：导出对应扫描页，画廊及舞台保留实际原图，统一加入柔和色调、边框、舞台灯光与前景对话层。第一课以原图为参考生成彩色车厢场景，建立逐课重绘样例。其余课程若尚未完成彩色重绘，应明确标记为教材插画版，不宣称已完成 144 张独立彩色背景。每张重绘保存来源页、生成提示词与文件路径。

## 数据及接口

`content/book1.json`：版本、144 课的编号、标题、课型、PDF 页、配对音频 URL、带时间戳的原文句子、场景路径。素材文件使用数字编号 URL，服务器查白名单映射回原文件，禁止任意路径读取。

`data/save.json`：schemaVersion、角色列表、角色进度与奖杯。每角色有 ID/name/avatar/createdAt；进度按 lessonId 保存对话 cursor 和 lastDifficulty，按难度保存 bestScore/attempts/trophy。星光按奖杯计算，避免冗余数据不一致。客户端仅存当前角色 ID；服务器存档为准。

| API | 用途 |
| --- | --- |
| GET /api/health | 服务健康 |
| GET /api/lessons | 课程目录 |
| GET /api/lessons/{id} | 课程与时间轴 |
| GET /api/players / POST /api/players | 列出与创建角色 |
| GET /api/players/{id} | 进度与奖励 |
| PUT /api/players/{id}/progress | 保存合法课次和对话位置 |
| POST /api/players/{id}/attempts | 创建固定题目的测验会话 |
| POST /api/players/{id}/attempts/{attemptId} | 提交答案、判分、保存奖励，重试幂等 |
| GET /media/audio/{pairId} | 支持 Range 的原音频 |
| GET /api/backup | 下载完整家庭存档备份 |

家庭本地模式无密码、不隔离家庭成员间角色访问。非受信网络部署前需要另加身份认证，当前版本不直接面向公网。

## 错误处理与验证

名字、课号、难度、句子索引均在服务器校验；请求大小有上限；存档损坏启动报错，不能静默覆盖；存盘失败不返回成功；客户端网络错误显示重试提示。素材缺失启动检查报错。答题提交按钮防连点，后端幂等。

测试覆盖：LRC 时间与过滤、144 课映射完整性、角色重启恢复、难度判分边界、奖励不重复、角色数据分离、非法参数、存盘失败及音频 Range。浏览器验证覆盖建角、选课、播放、挑战、奖杯、刷新恢复和窄屏。
