## 范围

采用原生 WXML/WXSS/JavaScript 小程序，复用 Go 课程、判题、奖励与存档逻辑。保留 144 课与独立动漫插图、角色创建切换、12 章地图、逐句和连续播放、字幕定位、三档挑战、奖杯收藏、进度恢复。原 web 版本作为既有应用保留。

比较：web-view 套壳无法充分适配小程序音频、登录与页面体验；跨端框架需要新增构建链并重写已有 DOM。当前项目采用原生小程序，代码量和依赖更可控。

## 客户端与接口契约

- 小程序根目录 `miniprogram/`，页面为 `index`（地图）、`players`、`lesson`、`challenge`、`rewards`、`settings`。采用现有暖色绘本风格和中文引导。
- `config.json` 配置 `apiBase` 和 `devLogin`；AppID 使用用户提供的 `wx1f23b102bcb34ed7`。仓库不含真实域名或密钥，发布检查必须拒绝占位配置。
- `POST /api/session` 请求 `{code}`，返回 `{token, expiresAt}`；正常模式通过 `wx.login` 获取 code，Go 调用微信 code2Session 获取 openid。客户端不传 openid，不持有 AppSecret。
- 业务 API 沿用 `/api/lessons`、`/api/players`、`/progress`、`/attempts` 及原 JSON 格式，以 `Authorization: Bearer <token>` 请求。
- 角色按微信账号隔离，每账号支持多个自定义名字角色；角色 ID 不能跨账号读取、修改或领奖。备份只能返回当前账号。
- 图片与音频是只读教学素材，由独立小程序服务的 `/assets/scenes/`、`/assets/pages/`、`/media/audio/` 提供，支持音频 Range。不传登录 token 到素材 URL，也不公开存档目录。
- 音频使用 InnerAudioContext；切课、页面隐藏/卸载与挑战切题停止旧音频；逐句到终点暂停，连续播放同步 LRC。错误显示可重试提示。切页后迟到的请求不能更新新页面。
- 挑战固定五题，服务端判分，提交期间防重复点击，失败重试使用同一 attempt ID。每课每难度只首次获得星光。
- 分享只包含公开课号和页面路径，不包含 token、角色名或存档 ID。体验用户资格仍由微信平台控制。

## 后端与部署隔离

新增 `cmd/wechat-server`，默认监听 `127.0.0.1:8093`，独立存档目录 `data/wechat`。既有 `cmd/server`、网页密码和 `/var/lib/english-adventure` 不变。

生产环境要求 `WECHAT_APP_ID`、`WECHAT_APP_SECRET`、至少 32 字节的 `WECHAT_SESSION_KEY`。签名会话有有效期，失败登录不能创建身份；错误不泄露微信密钥、code 或 session_key。按不可逆账号摘要分隔存档。

显式本地开发模式允许固定开发 code，服务必须限制回环监听及本地请求；发布检查拒绝开发模式。用于未申请 AppID 时的本地集成验证，不能冒充微信真实登录。

部署新增独立 systemd 服务与单独域名的 Caddy 示例。上线小程序服务不会替换现有网页进程或改变 main。后端部署、微信开发者工具真机测试、上传体验版、设为体验版及体验成员配置需要真实账号与域名条件。

云托管部署使用 MySQL 替代容器本地文件：每账号一份版本化状态，事务锁定账号行，角色/进度/奖励/未完成挑战原子提交；响应仅在事务成功后返回。按账号序列化请求，多实例不会依赖进程内缓存。数据库采用既有环境配置，不自动购买或创建云资源。保留本地 JSON 模式供家庭服务器和本机测试使用。素材在构建阶段从已推送的固定版本取得，避免把数百 MB 图片放入微信代码包。默认 CloudBase 域名仅作为体验测试入口，正式运营需自定义域名及平台配置。
