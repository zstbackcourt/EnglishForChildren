# 改动与优化记录

每条记录对应一次有意义的改动，保留原因、方案和验证，不覆盖历史结论。

## 001 2026-10-22 需求与素材审计

- 目标：先完成方案，再实现第一册家庭学习游戏。
- 发现：PDF 为 299 页扫描件；72 组美音 LRC 按双课命名；所谓英音 ZIP 仅含 PNG。
- 方案：144 课独立编号，奇数对话与偶数练习分别展示；偶数课明示复用配对音频；原仓库不改动。
- 文件：docs/design.md、docs/implementation-plan.md、docs/changes.md。
- 验证：读取 ZIP 目录、枚举第一册 LRC、检查首三份 LRC、渲染查看 PDF 第 5/7/13 页。
- 状态：文档已落地；实现与逐课内容审计待后续记录。

## 002 2026-10-22 家庭存档架构

- 依据：用户确认家庭多角色、本地服务器存档。
- 方案：Go 标准库 + 原生 JavaScript；家庭单实例 JSON 原子存盘；每角色独立 ID，名字不是身份凭证；本地备份下载。
- 取舍：暂不引入需要额外下载的数据库或前端框架，核心存档通过接口封装，便于以后迁移 SQLite。
- 验证计划：重启持久化、角色隔离、奖励幂等、损坏存档拒绝覆盖。

## 003 2026-10-22 全册内容导入

- 问题：扫描 PDF 无文本层，72/73 课间还插入 4 页阶段测试，按固定页偏移会错配。
- 修改：本地 Vision OCR 定位课首，导出 299 页图，人工核对 51/140/142 三个异常；生成 144 单元、72 组原音频、1226 条正文时间轴。
- 文件：scripts/import_content.py、scripts/ocr_pdf.swift、content/book1.json、web/assets/pages、docs/content-audit.md。
- 验证：先执行缺失目录的失败测试，再导入，素材完整性测试通过；人工查看首课、练习课、51/140/142 课。
- 限制：其余台词沿用源 LRC；未逐句人工听校全册。系统 Python 3.8 解析超长中文行异常，导入使用 bundled Python 成功，后续整理脚本兼容性。

## 005 2026-10-22 API 与路由修复

- 修改：课程/角色/进度/挑战/备份 API，白名单音频路径，Range 分段读取，跨站请求拦截。
- 发现：Go ServeMux 的 GET 根路由与不限方法 API fallback 匹配范围冲突。
- 方案：静态根路由与 fallback 使用相同方法范围，具体 API 仍限定方法，消除注册冲突。
- 验证：新增 HTTP 测试先暴露失败；修复后重新执行 race 测试。

## 007 2026-10-22 浏览器流程与题目去重

- 验证：独立测试服务 8081 / tmp/qa-save.json 中建角、播放第一课、5/5 通关、获得金杯和 30 星光，刷新后奖杯与星光保留。浏览器未报告 JS 错误。
- 发现：源对话中的相同句子会被抽到两次；新增去重回归测试确认失败。
- 优化：按规范化正文去重，纳入单词回应句，优先抽取不同语句；单词排序仍要求至少两个词。
- 验证：144 课 × 3 难度生成测试、Go race、go vet、JS 字幕测试、素材测试通过。
- 优化：窄屏隐藏冗长英文副标题、导航不换行；音频使用播放代次取消过期加载，避免退出后迟到播放；导入脚本长中文行拆分后系统 Python 3.8 可运行。
- 文件：quiz.go、http_test.go、audio.js、styles.css、scripts/import_content.py。

## 008 2026-10-22 审查发现的异步竞态

- 发现：测验创建或提交请求尚未完成时切换角色/页面，旧响应可能打开旧题目或覆盖新页面。
- 方案：请求捕获角色、课程、页面代次和测验代次；关闭或导航后忽略过期 UI 响应；服务器已提交的成绩仍正常保存。角色选择也加入代次检查。
- 文件：web/app.js、web/app-race.test.js。
- 验证：用实际 startQuiz/renderQuiz 函数与延迟请求重现两种竞态，修复前 2 个测试失败，修复后全部通过。
- 说明：关闭 dialog 的延迟事件只停止播放，不取消刚创建的新挑战；同步关闭动作与 Escape 才使旧挑战代次失效。

## 010 2026-10-22 提交后关闭弹窗的奖励刷新

- 发现：测验提交过程中关闭弹窗，成绩虽已保存，当前角色的奖杯室仍可能展示旧值。
- 方案：提交后始终刷新同一角色的数据；页面变化时只更新地图/奖励视图，不重开测验；切换角色后不覆盖新角色。
- 文件：web/app.js、web/app-race.test.js。
- 验证：新增延迟提交回归用例先失败后通过；4 项 JS 测试全部通过，独立审查确认修复。
