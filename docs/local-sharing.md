# 本地运行、外网访问

## 方案

Go 游戏在本机 `127.0.0.1:8080` 运行，Cloudflare Quick Tunnel 把临时 HTTPS 地址转发到本机。角色、进度、奖杯仍保存在 `data/save.json`。不创建 Render 服务，不购买云服务器，不修改路由器端口。

`share.sh` 管理游戏、隧道及临时防休眠进程；先检查端口和家庭密码保护再开启隧道。`data/share` 保存密码、状态、日志及控制套接字，全部被 Git 忽略。只对同一台机器的当前用户提供停止控制，不通过公网提供管理接口。

## 安装与启动（macOS / Linux）

首次安装隧道工具：

```bash
bash scripts/install_cloudflared.sh
```

macOS 使用 Homebrew 安装 cloudflared 并校验签名；若未安装 Homebrew，请先按 https://brew.sh 的说明安装。Linux amd64/arm64 从 Cloudflare 官方 GitHub 下载固定版本，并核对 SHA256。

先停止现有 `./start.sh` 游戏进程，再执行：

```bash
./share.sh
```

出现“隧道已连接”后执行 `./share.sh status` 查看地址。用户名固定为 `family`，密码在 `data/share/password.txt`。把地址和密码私下发给受信任的使用者；当前游戏是共享家庭空间，所有登录者都可以选择其中的角色。

首次生成随机密码，权限 0600；之后重启复用同一密码。密码不包含在进程参数、隧道日志或 Git 中。换密码时先停止分享，再编辑该文件（至少 16 个字符），然后重启。

停止分享：

```bash
./share.sh stop
```

也可以在运行终端按 Ctrl+C；游戏、隧道和防休眠进程一起停止，学习存档保留。继续仅本机使用时执行 `./start.sh`。不要同时开启多个进程写同一份 `data/save.json`。

## 限制与故障定位

- 临时链接每次建立隧道都会变化；退出脚本、电脑断网/关机后失效。
- macOS 分享期间暂时阻止空闲休眠；合盖或主动休眠仍可能断线。
- `data/share/server.log` 为游戏日志，`tunnel.log` 为隧道日志；120 秒未建立连接会自动停止，避免留下不明确的分享状态。
- 端口占用不会自动终止其他应用。需要先停止旧游戏；不能仅换端口同时写同一份存档。
- Quick Tunnel 是试用/开发用途，没有可用性保证；固定域名和长期服务需正式 Tunnel。参见 [官方说明](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/)。
- 外网访问可能受本机网络或接收方网络限制；分享前应让朋友使用手机流量实际打开一次。

## 当前机器的验证结果（2026-10-22）

密码生成与持久化、权限、URL 提取、子进程终止测试通过；本机服务确认未登录访问角色接口返回 401、正确密码返回 200。启动与失败后的子进程清理已实际执行。

官方下载的 macOS arm64 cloudflared 2026.10.3 tgz 与 GitHub 资产摘要一致（1165d14b…45f3ec55），但 macOS `codesign --verify --strict` 报签名无效，实际隧道进程退出 137。替换安装包下载/诊断请求未获批准，因此未继续替换或绕过校验。安装脚本改用 Homebrew 渠道，但尚未执行该安装方式。

**当前尚无已验证可用的外网游戏链接。** 本地游戏已恢复；需要安装签名有效的 cloudflared 后继续执行外网播放、写入进度与重启验证。不要把脚本已实现视为隧道已接通。

## 为什么 2DMH 可以直接发链接

2DMH 是纯前端静态游戏，发布到 chatgpt.site，存档在各玩家的浏览器中。本项目按“Go 后端、家庭服务器存档”的要求实现，需要运行后端。隧道保留当前存档模式；若另做纯前端版，可以像 2DMH 一样静态发布，但存档会变为各浏览器独立保存，不能直接复用当前服务器存档模式。
